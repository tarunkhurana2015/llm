## Environment setup:

If the environment already exists, just activate it:

    conda activate env_minigpt
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

If you need to create it first:

    conda create -n env_minigpt python=3.13 -y
    conda activate env_minigpt
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

This project already has a conda environment named `env_minigpt` available on this machine.
